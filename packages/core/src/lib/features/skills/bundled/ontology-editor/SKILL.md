# 本体编辑

本技能帮助你通过对话式界面编辑知识图谱中的实体和关系。

## 功能

- 查询现有实体和关系
- 创建新实体
- 更新实体属性
- 删除实体
- 创建和删除关系
- 验证图结构

## 使用方式

你可以直接用自然语言描述你的操作，例如：

- "显示所有项目实体"
- "创建一个名为 '新项目' 的项目实体"
- "更新项目 proj_001 的描述为 '这是一个重构项目'"
- "给张三和李四之间添加 'collaborates_with' 关系"
- "删除任务 task_123"
- "验证本体图结构"

## 执行指导

处理用户请求时：

1. **理解意图**：分析用户的自然语言输入，确定要执行的操作类型

2. **识别操作类型**：
   - 查询：包含"显示"、"列出"、"查询"、"查看"、"show"、"list"、"query"、"display"等关键词
   - 创建：包含"创建"、"新建"、"添加"、"建立"、"create"、"new"、"add"等关键词
   - 更新：包含"更新"、"修改"、"编辑"、"修改"、"update"、"edit"、"modify"等关键词
   - 删除：包含"删除"、"移除"、"remove"、"delete"等关键词
   - 验证：包含"验证"、"检验"、"检查"、"validate"、"check"等关键词

3. **提取参数**：
   - 实体类型：匹配"项目"、"任务"、"人员"、"目标"、"project"、"task"、"person"、"goal"
   - 实体ID：匹配 pattern `[a-z]+_[a-z0-9]+`
   - 实体名称：从引号或命名模式中提取
   - 属性更新：
     - 描述：包含"描述为："、"description："模式
     - 名称/标题：包含"改为"、"name："、"title："模式

4. **提供流式响应**：
   - 首先确认用户的意图
   - 逐步显示执行进度
   - 提供中间状态更新
   - 最终确认结果
