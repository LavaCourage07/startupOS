# 信息查询

本技能帮助你通过对话式界面查询项目相关信息。

## 功能

- 查询项目详情
- 查询任务信息
- 查询团队成员信息
- 查询目标进度
- 关系查询（如查询某个人员的所有任务）
- 统计信息（如任务数量、状态分布等）

## 使用方式

你可以用自然语言提出问题，例如：

- "这个项目有多少个任务？"
- "显示张三负责的所有任务"
- "项目的目标是什么？"
- "哪些任务正在进行中？"
- "查询项目的团队成员"
- "项目中有多少个人？"

## 执行指导

处理用户查询时：

1. **理解查询意图**：分析用户的自然语言输入，确定查询类型

2. **识别查询类型**：
   - 数量统计：包含"多少"、"数量"、"几个"、"how many"等关键词
   - 状态查询：包含"进行中"、"完成"、"待处理"、"in_progress"、"done"、"open"等关键词
   - 人员相关：包含"张三"、"人员"、"成员"、"person"、"member"、"team"等关键词
   - 关系查询：包含"某人负责"、"某人的任务"等模式
   - 项目详情：包含"项目信息"、"项目目标"等关键词

3. **提取参数**：
   - 实体类型：匹配"项目"、"任务"、"人员"、"目标"、"project"、"task"、"person"、"goal"
   - 人员姓名：匹配中文姓名模式或英文名
   - 状态关键词：
     - "进行中"/"in_progress" → in_progress
     - "完成"/"done"/"finished" → done
     - "待"/"待处理"/"open"/"todo" → open

4. **提供流式响应**：
   - 首先确认查询意图
   - 逐步显示查询进度
   - 提供查询结果摘要
   - 展示详细信息
