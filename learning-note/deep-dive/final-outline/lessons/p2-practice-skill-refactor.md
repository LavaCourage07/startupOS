> 类型：综合实战大纲

## 本节定位

- 范围：一个 `templates/skills/*`、Skill loader、SkillDialog 或输出目录
- 图解：Skill definition -> loader -> Agent session -> artifact
- 验收：能解释 Skill 定义、加载、prompt 注入和产物路径。

## 完整版课件要求

- 使用固定结构：问题 -> 图解 -> 源码入口 -> 调用链 -> 关键类型 -> 测试入口 -> 练习 -> 验收。
- 至少包含 1 张 Mermaid 图。
- 如本节涉及核心概念、复杂心智模型或阶段总结，需要加入 Xiaohei 配图。
- 源码入口必须写真实路径，不能只写模块名。
- 调用链必须能从入口追到下一层实现或明确说明边界。
- 测试入口必须写真实测试路径；没有测试时要说明缺口。
