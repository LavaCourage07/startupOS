# Part M：非源码文件如何阅读——从 782 个文件到 5 条轨道

## 课程定位

Part M 是 OriginOS 全项目课程的第 13 部分，解决一个核心问题：**当你面对 782 个非源码文件时，怎样系统性地阅读、理解和判断它们？**

非源码文件不是"不重要的文件"——它们定义了系统的架构约束（文档）、决定了产物的生成方式（构建）、存储了用户的数据（数据）、影响了应用的外观和权限（资源）、以及验证了系统的正确性（测试）。忽略这些文件，就无法真正理解 OriginOS 的全貌。

## 学习路径

### 推荐学习顺序

1. **按单元顺序学习**：Unit 1 → Unit 2 → Unit 3 → Unit 4 → Unit 5
2. **每单元内按课次顺序学习**：M01 → M02 → ... → M07
3. **每单元结束后做综合复盘**：M07、M13、M18、M23、M28

### 快速定位

如果你已经熟悉某些轨道，可以跳过：

- **只关心文档**：Unit 1（M01—M07）
- **只关心构建**：Unit 2（M08—M13）
- **只关心数据**：Unit 3（M14—M18）
- **只关心资源**：Unit 4（M19—M23）
- **只关心测试**：Unit 5（M24—M28）

## 口头验收标准

学完 Part M 后，不看正文也应能回答：

1. 782 个非源码文件分布在哪些轨道？每个轨道的核心文件是什么？
2. 如何从索引定位到任何文档？如何判断文档的完整度和可信度？
3. 从代码提交到用户下载，构建链路包含哪些环节？
4. 数据的生命周期是怎样的？从创建到删除经历了哪些阶段？
5. 资源文件如何被构建系统使用？如何适配不同平台？
6. 测试金字塔的理念是什么？如何评估测试的充分性？

合格回答不要求背诵每个文件的具体内容，但必须能说清每个轨道的核心能力、关键依赖关系、以及问题排查方法。能说清"非源码文件的全貌"比只说清"某个文件的作用"更重要。
