# F54：ProjectAgent 边界与扩展点

## 开篇场景

ProjectAgent 已经实现了项目上下文加载、6 层 prompt、多 Agent 协作、技能幂等补齐等核心功能。但还有一些边界问题和扩展点需要关注。

## 核心问题

**ProjectAgent 有哪些已知限制？未来可以扩展什么？**

## 已知限制

### 1. 阶段判断

- 当前通过 `business-model.json` 的存在与否判断阶段；
- 不支持更细粒度的阶段定义（如 RoleAgent 的状态机）。

### 2. 协作协议

- `extractCollaborationSection` 使用正则匹配，对格式敏感；
- 不支持动态协作协议更新。

### 3. 技能管理

- 当前只支持从 bundled skills 复制；
- 不支持用户自定义技能。

## 扩展点

### 1. 动态阶段定义

- 支持类似 RoleAgent 的状态机；
- 支持自定义阶段和转换规则。

### 2. 协作协议可视化

- 当前协作协议是文本定义；
- 未来可以支持图形化编辑。

### 3. 技能市场

- 支持从远程仓库下载技能；
- 支持技能版本管理。

## 练习与验收

1. **分析限制**：找出至少 3 个已知限制。
2. **设计扩展**：为“动态阶段定义”设计实现方案。

**验收标准**：能分析 ProjectAgent 的限制和扩展点。
