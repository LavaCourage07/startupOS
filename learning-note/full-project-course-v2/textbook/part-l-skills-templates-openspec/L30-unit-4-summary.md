## 核心概念地图

### 1. 两阶段访谈模式

```
Phase 1: 领域发现 (Discovery)
  → 开放式提问
  → 识别行业领域
  → 收集初步信息

Phase 2: 业务精炼 (Refinement)
  → 结构化追问
  → 填补信息缺口
  → 检测矛盾
  → 完善业务规则
```

### 2. 领域发现

| 步骤 | 目标 |
| --- | --- |
| 识别领域 | 确定行业、核心活动、干系人 |
| 定义边界 | 确定范围、约束 |
| 提取概念 | 识别实体、关系、规则 |
| 验证模型 | 检查完整性、一致性 |

### 3. 业务精炼

| 步骤 | 目标 |
| --- | --- |
| 结构化追问 | 填补信息缺口 |
| 矛盾检测 | 发现不一致 |
| 规则完善 | 补充约束 |
| 验证 | 确认完整性 |

### 4. 访谈进度管理

| 内容 | 说明 |
| --- | --- |
| 已完成阶段 | 记录当前进度 |
| 已识别概念 | 记录发现的业务概念 |
| 待确认问题 | 记录需要用户确认的问题 |
| 发现矛盾 | 记录检测到的矛盾 |
| 下一步计划 | 记录后续步骤 |

## 本单元结论

本单元建立了 Project Interview Templates 的完整认知：

- **两阶段访谈**：领域发现 + 业务精炼
- **领域发现**：识别领域 → 定义边界 → 提取概念 → 验证模型
- **业务精炼**：结构化追问 → 矛盾检测 → 规则完善 → 验证
- **访谈进度管理**：持续更新进度文件，记录进度和问题
- **访谈助手**：引导、识别、记录、检测、建议
