# Unit 4 导学：Project Interview Templates

> 本单元问题：OriginOS 如何通过项目访谈模板完成从想法到业务模型的转化？

## 本单元核心问题

项目访谈是 OriginOS 的核心功能之一。通过结构化的对话，系统帮助用户从模糊的想法出发，逐步构建完整的业务领域模型。

本单元将回答：

1. **`project-initialization`**：项目访谈的两阶段模式
2. **`domain-discovery`**：领域发现
3. **`business-refinement`**：业务精炼
4. **访谈进度管理**：如何追踪和管理访谈进度

## 学习路线

```
L26: project-initialization — 项目访谈的两阶段模式
L27: domain-discovery — 领域发现
L28: business-refinement — 业务精炼
L29: 访谈进度管理
L30: 单元小结
```

## 核心概念预览

### 两阶段访谈模式

```
Phase 1: 领域发现 (Discovery)
  → 引导用户描述业务场景
  → 识别行业领域
  → 收集初步信息

Phase 2: 业务精炼 (Refinement)
  → 结构化追问
  → 填补信息缺口
  → 检测矛盾
  → 完善业务规则
```

### 访谈产物

| 产物 | 说明 | 位置 |
| --- | --- | --- |
| **访谈记录** | 对话历史 | `data/interviews/` |
| **业务模型** | 领域、概念、关系 | `data/ontology/` |
| **进度文件** | Markdown 格式的进度追踪 | 项目目录 |

3. **掌握业务精炼的方法**：结构化追问、矛盾检测
4. **了解访谈进度管理**：如何追踪和管理访谈进度
