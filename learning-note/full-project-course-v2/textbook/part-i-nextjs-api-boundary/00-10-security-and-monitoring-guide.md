## 7. 异常排查

当小林说"身份验证失败""日志未记录""监控未告警"时，最稳的排查方式是先确认身份验证，再确认日志记录，最后确认监控告警。

```mermaid
flowchart TD
    A[安全/监控异常] --> B{身份验证?}
    B -->|是| C[检查 auth.ts]
    B -->|否| D[检查 logger.ts]
    D --> E[检查 monitor.ts]
```

排查口诀：

1. 先看身份验证，确认令牌有效。
2. 再看日志记录，确认日志输出。
3. 最后检查监控告警，确认告警触发。
