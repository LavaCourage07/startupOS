# I42：响应式设计：适配不同屏幕

上一节课看了 CSS 变量。这节课看响应式设计如何实现。

## 1. 文件用途

响应式设计让 OriginOS 适配不同屏幕尺寸，包括：

- 断点定义
- 布局调整
- 字体大小

## 2. 核心实现

### 2.1 Tailwind 断点

| 前缀 | 断点 | 说明 |
| --- | --- | --- |
| `sm:` | 640px | 小屏幕 |
| `md:` | 768px | 中等屏幕 |
| `lg:` | 1024px | 大屏幕 |
| `xl:` | 1280px | 超大屏幕 |
| `2xl:` | 1536px | 特大屏幕 |

### 2.2 响应式类

```html
<div class="text-sm md:text-base lg:text-lg">
  响应式文本
</div>
```

- `text-sm`：默认小字体。
- `md:text-base`：中等屏幕以上中等字体。
- `lg:text-lg`：大屏幕以上大字体。

## 3. 核心逻辑

### 3.1 移动优先

Tailwind CSS 采用移动优先策略：

```html
<div class="w-full md:w-1/2 lg:w-1/3">
  响应式宽度
</div>
```

- `w-full`：默认全宽。
- `md:w-1/2`：中等屏幕以上 50% 宽度。
- `lg:w-1/3`：大屏幕以上 33% 宽度。

### 3.2 隐藏与显示

```html
<div class="hidden md:block">
  中等屏幕以上显示
</div>
```

- `hidden`：默认隐藏。
- `md:block`：中等屏幕以上显示。

## 4. 失败路径

### 4.1 断点配置错误

如果断点配置错误，响应式效果可能不正确。

### 4.2 类名冲突

如果类名冲突，样式可能覆盖。

## 6. 小实验

不运行项目，回答：

1. Tailwind CSS 的断点有哪些？
2. 什么是移动优先策略？
3. 如何在中等屏幕以上显示元素？

参考答案：

1. `sm`, `md`, `lg`, `xl`, `2xl`。
2. 默认样式应用于小屏幕，大屏幕通过断点覆盖。
3. 使用 `hidden md:block`。
