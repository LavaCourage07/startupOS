# I39：page.tsx：主页的定义

上一节课看了 `layout.tsx`。这节课看 `page.tsx`。

## 1. 文件用途

`page.tsx` 定义了 OriginOS 的主页，包括：

- 页面内容
- 组件渲染

## 2. 核心实现

打开 `app/page.tsx`：

```tsx
export default function Home() {
  return <main>Home</main>;
}
```

## 3. 核心逻辑

### 3.1 页面内容

```tsx
<main>Home</main>
```

- `main`：HTML5 语义化标签。
- `Home`：页面标题。

### 3.2 与 layout.tsx 的区别

| 维度 | layout.tsx | page.tsx |
| --- | --- | --- |
| 作用 | 根布局 | 页面内容 |
| 渲染次数 | 一次 | 每次导航 |
| 状态保持 | 是 | 否 |
| 典型用途 | 全局导航、主题 | 页面内容 |

## 4. 失败路径

### 4.1 组件加载失败

如果页面组件加载失败，页面会显示空白或错误。

### 4.2 内容为空

如果页面内容为空，页面会显示空白。

## 5. 测试证据

| 验证方式 | 能证明 | 不能证明 |
| --- | --- | --- |
| 浏览器访问 | 页面能渲染 | 内容一定正确 |
| 代码阅读 | 逻辑清晰 | 所有浏览器兼容 |

## 6. 小实验

不运行项目，回答：

1. `page.tsx` 和 `layout.tsx` 有什么区别？
2. 如果 `page.tsx` 中没有内容，会发生什么？
3. `<main>` 标签的作用是什么？

参考答案：

1. `page.tsx` 定义页面内容，`layout.tsx` 定义根布局。
2. 页面显示空白。
3. `<main>` 是 HTML5 语义化标签，表示主要内容。
