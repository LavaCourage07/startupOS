# 单元八导读与复盘：证据、故障诊断与综合验收

本单元回答一个问题：怎样证明 Core 基础设施不是“看起来有代码”，而是真的能被追踪、诊断和验收。

主线把前七个单元的路径、存储、类型、合同和 port 放回同一条正向恢复链路，再从“重启后项目消失”做反向诊断。读者需要学会区分源码事实、类型检查、测试证据、合理推断和测试缺口。

## 正式课

| 课次 | 作用 |
| --- | --- |
| D31 | 合并讲解证据等级、路径测试、Zod 测试和消费者测试的证明上限。 |
| D32 | 用正向追踪和反向诊断定位“重启后项目消失”。 |
| D33 | 完成 Core 基础设施总验收工作坊，并连接 Part E。 |

## 小结课验收

读者必须能拿一个失败症状，按路径、写入、文件、解析、映射、展示的顺序查证，并能说清每一步需要什么证据，缺什么测试。
