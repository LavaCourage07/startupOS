# 单元一导读与复盘：路径与数据根目录

本单元回答一个问题：课程助手项目关闭窗口、退出进程之后，系统怎样在下一次启动时重新找到同一份数据。

主线从一个内存里的 `Project` 对象开始，先区分内存生命周期、窗口生命周期、进程生命周期和文件生命周期，再进入 `packages/core/src/lib/paths.ts`。读者需要学会从 `DATA_ROOT`、Electron 注入路径和 monorepo fallback 三种入口推导真实数据根目录。

## 正式课

| 课次 | 作用 |
| --- | --- |
| D01 | 建立“为什么必须先讲路径”的问题背景。 |
| D02 | 合并讲解 `getMonorepoRoot()`、`getDataRoot()` 和运行环境优先级。 |
| D03 | 合并讲解项目、Agent、Skill、模板目录和只读技能源边界。 |
| D04 | 用三种运行环境做路径工作坊，完成本单元小结。 |

## 小结课验收

读者必须能拿到一个运行环境输入，推导项目元数据、项目工作目录、Agent 产物目录和 Skill 产物目录分别落在哪里，并说明哪些结论来自源码，哪些只是环境推断。
