# 单元二导读与复盘：JSON 存储生命周期

本单元回答一个问题：一个课程助手项目怎样从业务对象变成磁盘 JSON，又怎样在重启后被读回。

主线进入 `packages/core/src/lib/storage/json-store.ts`。读者需要学会区分 `DataFile<T>` 外壳、业务 payload、目录初始化、写入副作用、读取失败语义、浅合并更新和 typed path helper。

## 正式课

| 课次 | 作用 |
| --- | --- |
| D05 | 合并讲解 `DataFile<T>` 和 `JsonStore` 单例保存的状态。 |
| D06 | 合并讲解初始化目录与第一次写入。 |
| D07 | 合并讲解缺失文件、损坏 JSON 和系统 I/O 错误。 |
| D08 | 合并讲解更新、删除、存在性检查和列表的不同失败合同。 |
| D09 | 用保存、损坏、恢复实验完成本单元小结。 |

## 小结课验收

读者必须能用一个具体 `Project` 输入写出磁盘文件的大致形状，并能从“重启后项目消失”反查路径、写入、文件存在、JSON 解析和返回映射。
