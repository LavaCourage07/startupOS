# 单元四导读与复盘：项目、访谈与本体合同

本单元回答一个问题：课程助手项目为什么不能只用一个 `Project` 类型描述完整创建过程。

主线从项目实体进入项目创建请求、创建会话、访谈记录和本体结构。读者需要学会区分长期项目身份、一次创建请求、步骤式创建会话、访谈结果和领域/概念/实例三层本体。

## 正式课

| 课次 | 作用 |
| --- | --- |
| D14 | 合并讲解 `Project` 实体、创建、更新、列表和查询合同。 |
| D15 | 合并讲解项目 API、Zod 创建 schema、创建会话和进度函数。 |
| D16 | 合并讲解访谈问题、答案、结果和状态。 |
| D17 | 合并讲解本体核心实体、图谱实体、关系类型和平行定义边界。 |
| D18 | 从创建请求推演到可恢复本体，完成本单元小结。 |

## 小结课验收

读者必须能说明一个项目从“用户输入名称和领域”到“形成可恢复本体雏形”期间，哪些对象是请求，哪些对象是会话状态，哪些对象会长期保存。
