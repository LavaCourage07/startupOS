# 单元六导读与复盘：Solution 与 TASTE 合同

本单元回答一个问题：当课程助手从单个项目扩展为可交付方案时，Core 怎样描述方案结构、交付清单和偏好数据。

主线进入 `solution.ts`、`solution-manifest.ts` 和 `taste.ts`。读者需要学会区分 Solution 的协作结构、Manifest 的文件交付合同、TASTE Profile 的运行时 schema、偏好合并和分析进度。

## 正式课

| 课次 | 作用 |
| --- | --- |
| D24 | 合并讲解 Solution 状态、方案结构、Skill 输入输出、SOP 步骤和协作拓扑。 |
| D25 | 合并讲解 manifest bundle、版本、agents、skills 和文件集合。 |
| D26 | 合并讲解 TASTE Profile、metadata、来源、validator、merge 和 progress。 |
| D27 | 创建、合并并判断方案与偏好是否可用，完成本单元小结。 |

## 小结课验收

读者必须能判断一个方案对象是否已经足以交付，哪些信息属于方案结构，哪些信息属于打包清单，哪些信息属于用户偏好画像。
