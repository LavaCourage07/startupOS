# 单元七导读与复盘：Shared Ports 与依赖倒置

本单元回答一个问题：Core 为什么要声明 shared port，而不是让高层逻辑直接依赖具体实现。

主线进入 `packages/core/src/lib/shared/**`。读者需要学会区分 port、adapter、定义文件解析、模型创建、认知数据记录和公共出口。这个单元不追求文件数量多，而追求把依赖方向讲准确。

## 正式课

| 课次 | 作用 |
| --- | --- |
| D28 | 合并讲解依赖方向、port/adapter 模型、shared 根出口和子目录出口。 |
| D29 | 合并讲解 Agent、Model、Cognitive 三组 port 抽离的变化点。 |
| D30 | 替换实现而不改上层合同，完成本单元小结。 |

## 小结课验收

读者必须能用一个 fake adapter 替换具体实现，说明上层代码为什么只依赖接口，并指出这种替换不能证明真实生产入口已经接通。
