# 单元导读二：一条回复怎样从服务端慢慢出现（E09-E20）

## 这一组课解决什么问题

输入框按下发送后，浏览器不能直接替模型工作。它需要创建或找到会话、把请求送到服务端、持续接收增量内容，再安全地更新界面。E09-E20 学这条跨边界链路。

## 先建立直觉

普通请求像寄一封信：寄出，等待，收到完整回信。流式回复像接通电话：服务端不断送来一小段，页面不断把新内容接到已有内容后面。会话 ID 保证这些片段回到正确的对话框。

## 你会依次学到什么

- 客户端 Hook 为什么保存界面状态，而服务端为什么拥有运行时实例。
- 创建会话、发送消息、取消请求的请求与响应边界。
- 流、事件、增量和最终消息各代表什么。
- 多个窗口同时发送时，如何避免内容串流。
- 如何识别重复片段、过快渲染和异常中断。
- 哪些测试证明隔离、顺序和失败处理，哪些测试仍然缺失。

## 学完后的能力

你能沿源码追踪一次发送操作，指出浏览器、API 边界、AgentManager 和 UI 分别拥有的数据；也能解释“页面正在显示”不等于“服务端已经保存”。

## 与下一单元的关系

这一组证明一轮对话能跑起来；下一组解决它怎样跨越刷新、关闭和重启。
