# 单元导读四：Skill 怎样从文件变成 Agent 的工作说明（E31-E40）

## 这一组课解决什么问题

为什么“头脑风暴”和“创建 Agent”可以使用同一套会话运行时，却呈现不同能力？答案不是换了一个聊天框，而是会话加载了不同 Skill。E31-E40 追踪 Skill 从磁盘定义到 Prompt、再到产物目录的全程。

## 先建立直觉

Skill 可以理解为一份可加载的工作说明书：它有名称、描述和正文；运行时读取它，把合适内容放进提示词，并明确它能读哪里的参考资料、应把结果写到哪里。

## 你会依次学到什么

- bundled、project、user 三类来源为何需要明确优先级。
- frontmatter 与 Markdown 正文分别承担什么合同。
- 加载、诊断、过滤和格式化如何避免坏 Skill 破坏会话。
- `CLAUDE_SKILL_DIR` 与产物工作目录为什么绝不能混为一谈。
- Skill 中间件怎样影响 Prompt 和工具权限。
- fixture、输出目录和测试怎样证明来源隔离。

## 学完后的能力

你能从一个首页 Skill 名称追到定义文件，解释它进入提示词的路径，并判断某个输出目录是否违反只读技能源目录的规则。

## 与下一单元的关系

Skill 告诉 Agent“怎样做”；工具才真正让 Agent 能读文件、执行命令或访问外部资源。
