# 单元导读七：怎样证明 Agent 会话真的可靠（E64-E70）

## 这一组课解决什么问题

“我手动试过一次能回复”不是可靠性证据。E64-E70 把前六组的会话、消息、流、保存、Skill、工具和异常处理汇成测试策略与端到端验收。

## 先建立直觉

每种测试回答的不是同一个问题：单元测试证明一个函数的分支；集成测试证明几个模块的边界；端到端验收证明用户动作能抵达可观察结果。它们相互补充，谁也不能替代谁。

## 你会依次学到什么

- 如何从用户故事写出 Given、When、Then。
- 怎样为会话隔离、保存恢复、流式去重、Skill 输出目录与工具工作目录配对测试。
- mock 为什么有用，又为什么不能证明真实模型供应商一定可用。
- 测试夹具、临时目录与环境配置怎样避免污染真实数据。
- 如何组织一次从首页启动 Skill、发送消息、观察结果、关闭并恢复的验收。
- 如何如实报告未自动化部分、人工步骤和剩余风险。

## 学完后的能力

你能为一个最小 Agent 功能写出可审查的验证方案，并清楚区分“代码存在”“测试通过”“用户流程已验证”三种不同证据。

## Part E 收束

完成本单元后，你应能从一个用户请求出发，解释会话如何创建、消息如何流动、能力如何加载、工具如何行动、状态如何保存、错误如何受控，并用测试证明其中的关键承诺。
