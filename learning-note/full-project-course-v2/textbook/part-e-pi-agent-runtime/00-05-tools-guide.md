# 单元导读五：Agent 为什么能行动，又为何不能随意行动（E41-E55）

## 这一组课解决什么问题

模型只能产生建议文本；它要读取文件、运行命令、访问网页或写入项目内容，必须通过受约束的工具。E41-E55 讲工具的注册、工作目录、执行结果、错误、重试与安全边界。

## 先建立直觉

工具像一组带权限的操作按钮，而不是模型获得了操作系统的无限权限。每次调用都有名称、参数、工作目录、结果和失败状态；运行时据此把结果带回下一步推理。

## 你会依次学到什么

- 工具注册表如何决定某类 Agent 能看见哪些工具。
- 文件、命令、URL、文档、本体与 Skill 工具各自解决的任务。
- 工作目录为何要有优先级，怎样避免输出写进只读源目录。
- 工具调用、工具结果、退出码与错误信息如何形成一条可追踪记录。
- 循环检测、重试与用户提问如何阻止错误无限扩大。
- 工具测试怎样覆盖成功、拒绝和边界条件。

## 学完后的能力

你能说明一次“写文件”操作不是模型直接写盘，而是模型请求工具、运行时执行工具、工具结果再回到 Agent 的过程。

## 与下一单元的关系

当工具、流和长会话同时发生时，系统还需要防重复、控资源、记录健康状态；这就是下一单元。
