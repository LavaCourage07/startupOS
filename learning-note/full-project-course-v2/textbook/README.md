# OriginOS 源码教材

这里存放正式课件，不存放文件覆盖审计表或临时大纲。

## 编号规则

| 规则 | 含义 |
| --- | --- |
| `A01` | A Part 的第 1 节正式课；文件名必须以 `A01-` 开头。 |
| `E27` | E Part 的第 27 节正式课；文件名必须以 `E27-` 开头。 |
| 一个课号，一个 Markdown 文件 | 不在一篇文件中拼接多节课，便于链接、复习与记录进度。 |
| `README.md` | 只作本 Part 的导航；真正的讲解只写在各课文件中。 |

## 目录

| Part | 主题 | 正式课目录 |
