# 错题梳理与强化练习

帮助学生从试卷照片中自动识别错题，分析薄弱环节，并生成一份包含原错题和同类型变式题的 Word 练习卷，助力精准复习。

## 触发场景

- 学生上传试卷照片，希望梳理错题
- 用户提到"错题整理"、"考试复习"、"薄弱环节"、"错题卷"、"练习卷"等
- 家长帮孩子整理考试错题
- 老师需要为学生生成针对性练习
- 用户上传多张试卷照片进行批量分析

## 执行步骤

### Step 1: 确认学生信息

在开始处理前，向用户询问以下信息：

- **年级**：如"高一"、"初三"、"初二"等
- **学科**：如"数学"、"物理"、"英语"等
- **教材版本**（可选）：如"人教版"、"北师大版"等

这些信息用于准确对齐知识点和生成合适的变式题。

**操作**: 使用 ask_user_question 工具向用户确认年级和学科
**输出**: 学生信息（年级、学科、教材版本）

### Step 2: 识别试卷内容

对每张上传的试卷图片进行视觉分析：

1. **读取题目内容**：逐题提取题目文本、选项（如有）、图形描述
2. **识别批改标记**：重点关注红色笔迹的批改标记（红叉 ✗、红圈 ○、扣分标记等）
3. **判断错题**：被红色标记的题目即为错题

**操作**: 使用 AI 视觉能力逐张分析试卷图片
**输出**: 所有题目的列表，标注哪些是错题

注意事项：
- 如果图片模糊导致无法准确识别，提示用户重新拍摄
- 对于手写内容，尽力识别但可询问用户确认不确定的部分
- 保留原题的完整信息（题目、选项、图形描述）
- 如果有多张试卷，按试卷顺序依次处理

### Step 3: 按题型分类

将识别出的错题按题型进行分类：

- **选择题**（单选/多选）
- **填空题**
- **计算题**
- **解答题**
- **证明题**
- **阅读理解**
- **写作题**
- 其他自定义题型

统计每个题型的错题数量，形成初步的薄弱环节概览。

**操作**: 对错题按 question_type 字段分组统计
**输出**: 各题型的错题数量和占比

### Step 4: 分析薄弱环节

基于错题的题型分布和题目内容，深入分析学生的薄弱环节：

1. **题型维度**：哪些题型错误率高？哪些题型是学生的薄弱点？
2. **知识点维度**：错题涉及哪些核心知识点？（根据学科和年级判断）
3. **能力维度**：是基础知识不牢，还是综合应用能力不足？

输出一份简洁的薄弱环节分析报告，包括：
- 各题型错题数量及占比
- 核心薄弱知识点列表
- 针对性的复习建议

**操作**: 综合分析错题分布和内容，生成薄弱环节报告
**输出**: weakness_analysis 结构化数据

### Step 5: 生成变式练习题

针对每个薄弱环节（题型+知识点组合），生成同类型变式题：

- 变式题应与原错题考查相同的知识点和题型
- 难度与原题相当或略高，具有区分度
- 每个薄弱点生成 2-3 道变式题
- 题目应贴合对应年级和学科的教学要求
- 变式题必须包含完整答案和详细解析

**操作**: 基于薄弱环节分析，为每个知识点生成变式题
**输出**: variant_questions 列表，每题包含题目、选项、答案、解析

### Step 6: 生成 Word 练习卷

将所有数据整理为 JSON 格式，调用 scripts/generate_practice_test.py 脚本生成 Word 文档。

**操作**: 先生成 JSON 数据文件，再调用脚本生成 Word 文档
**输出**: 格式化的 Word 练习卷

#### 6.2 调用 Word 生成脚本

```bash
python3 skills/wrong-answer-review/scripts/generate_practice_test.py \
  --data /tmp/wrong_answer_data.json \
  --output /tmp/错题练习卷.docx
```

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| --data | 字符串（文件路径） | 是 | JSON 数据文件路径 |
| --output | 字符串（文件路径） | 是 | 输出 Word 文档路径 |

#### 6.3 输出结果

生成的 Word 文档包含以下部分：

1. **标题页**：「错题练习卷」+ 年级学科 + 生成日期
2. **薄弱环节分析**：
   - 总体分析摘要
   - 各题型错误统计表
   - 薄弱知识点列表
   - 复习建议
3. **第一部分：原试卷错题**：
   - 按题型分组展示
   - 每道题包含：题号、题目内容、选项、学生答案、正确答案
4. **第二部分：变式强化练习**：
   - 按关联的错题分组
   - 每道题包含：题目内容、选项（留空供学生作答）
5. **参考答案与解析**：
   - 变式题的完整答案和详细解析

## 输入格式

| 输入项 | 格式 | 说明 |
|--------|------|------|
| 试卷照片 | JPG/PNG | 一张或多张试卷的照片，包含红色批改标记 |
| 年级 | 文本 | 如"高一"、"初三"等 |
| 学科 | 文本 | 如"数学"、"物理"等 |
| 教材版本 | 文本（可选） | 如"人教版"、"北师大版"等 |

## 输出格式

一份 Word 文档（.docx），包含：
- 薄弱环节分析报告
- 原试卷错题（按题型分组）
- 变式练习题（同类型变式）
- 参考答案与解析

## 注意事项

1. **图片质量**：图片质量直接影响识别效果，建议提示用户拍摄清晰、光线充足的照片。如果图片模糊，应主动提示用户重新拍摄
2. **不确定内容**：对于无法确定的题目内容（如模糊的手写体），应主动向用户确认，不要猜测
3. **题目质量**：变式题必须确保题目质量和答案正确性，避免出现知识性错误
4. **排版要求**：Word 文档应排版清晰，方便打印使用。题目之间留有适当间距，答案部分单独成节
5. **图形处理**：如果试卷涉及图形/图表题，应在文档中用文字描述图形内容，必要时标注"（此处有图形，请参考原卷）"
6. **多试卷处理**：如果用户上传多张试卷，应按顺序依次处理，并在分析中注明每道错题的来源试卷
7. **年级适配**：变式题的难度和知识点应严格匹配学生的年级和学科要求，不要超出教学大纲范围
8. **python-docx 依赖**：生成 Word 文档需要 python-docx 库，如果未安装需先执行 pip install python-docx
