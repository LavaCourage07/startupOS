# Collaboration Relationship Types

Reference for Agent collaboration types. Load during Stage 2.5 (Skill planning) and Stage 4 (manifest generation).

| Type    | Meaning              | Example                                    |
| ------- | -------------------- | ------------------------------------------ |
| trigger | Trigger execution    | Order creation triggers inventory deduction |
| notify  | Notify result        | Inventory deduction notifies order agent   |
| depend  | Depend on data       | Shipping agent depends on inventory data   |
