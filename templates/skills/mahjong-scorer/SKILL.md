# 麻将计分器

三人麻将实时计分助手。玩家 GJ、CL、LL 对局，初始各 500 分。用户报出胡牌信息（谁胡、几分），自动计算分数变化并展示当前排名。

## 触发场景

- 用户说谁胡牌了、多少分（如"GJ胡了8分"、"CL自摸6分"）
- 用户想查看当前分数（如"现在几分了"、"当前排名"）
- 用户想查看对局记录（如"看看记录"、"之前几把"）
- 用户想重新开始（如"重新来一局"、"清零"）
- 用户提到麻将、打牌等上下文时

## 执行步骤

### Step 1: 初始化对局

首次使用时，创建三名玩家的初始分数记录：
- GJ: 500 分
- CL: 500 分
- LL: 500 分

同时创建一个对局记录文件来保存每一把的详细信息。

**操作**: 在 `skills/mahjong-scorer/` 目录下创建 `game-state.json`，记录当前分数和对局历史。
**输出**: 展示三位玩家的初始分数。

### Step 2: 记录胡牌

当用户报出胡牌信息时，解析以下内容：
- **胡牌者**：谁赢了（GJ / CL / LL）
- **分数**：胡了多少分
- **胡牌类型**（可选）：点炮（一人付）还是自摸（两家都付）

计算规则：
- **点炮**（默认）：放炮者扣对应分数，胡牌者加对应分数。第三家不变。
- **自摸**：其余两家各扣对应分数，胡牌者加对应分数的 2 倍。

> 如果用户没有明确说"自摸"，默认按点炮处理。用户只需说"自摸"即可切换为自摸计分。

**操作**: 读取 `game-state.json`，更新分数，追加对局记录。
**输出**: 展示本把结算详情和更新后的总分排名。

### Step 3: 查询状态

当用户想看当前情况时，展示：
- 三位玩家的当前分数
- 按分数从高到低排名
- 已进行的对局轮数

### Step 4: 查看对局记录

展示每一把的详细记录：
- 第几把
- 胡牌者、分数、类型（点炮/自摸）
- 放炮者（点炮时）
- 各玩家分数变化

### Step 5: 重新开局

清零所有分数，重新设为各 500 分，清空对局历史。

## 输入格式

用户用自然语言输入，支持以下说法：

| 用户说的 | 解析结果 |
|---------|---------|
| GJ胡了8分 | GJ 点炮胡 8 分 |
| CL自摸6分 | CL 自摸胡 6 分（每家付 6，CL 共得 12） |
| LL胡了10分，GJ放的 | LL 点炮胡 10 分，GJ 放炮 |
| GJ 5分 | GJ 点炮胡 5 分 |
| 自摸，CL，8 | CL 自摸胡 8 分 |

## 输出格式

### 每把结算

```
🀄 第 3 把
胡牌：GJ 点炮 8 分（放炮：CL）
  GJ: 508 → 516 (+8)
  CL: 492 → 484 (-8)
  LL: 500 → 500 (0)
```

### 当前排名

```
🏆 当前排名
1. GJ  516 分
2. LL  500 分
3. CL  484 分
```

### 自摸结算

```
🀄 第 5 把
胡牌：CL 自摸 6 分
  CL:  500 → 512 (+12)
  GJ:  516 → 510 (-6)
  LL:  500 → 494 (-6)
```

## 数据存储

使用本地 JSON 文件 `skills/mahjong-scorer/game-state.json` 存储游戏状态，格式如下：

```json
{
  "players": {
    "GJ": 500,
    "CL": 500,
    "LL": 500
  },
  "rounds": [
    {
      "round": 1,
      "winner": "GJ",
      "score": 8,
      "type": "dianpao",
      "loser": "CL",
      "changes": { "GJ": 8, "CL": -8, "LL": 0 },
      "timestamp": "2026-06-16T17:20:00+08:00"
    }
  ],
  "startedAt": "2026-06-16T17:20:00+08:00"
}
```

## 注意事项

- 默认按**点炮**计分，只有用户明确说"自摸"才按自摸算
- 点炮时如果用户没有说谁放炮，需要询问放炮者是谁
- 如果某位玩家分数不够扣，仍然正常扣（允许负分）
- 每次记录后都展示当前排名，方便大家随时了解局势
- 所有分数计算确保准确，这是钱的事情！💰
